📸 Element Screenshot

Capture screenshots of specific elements on the page

How to use:

  1. Click "Start Selection"
  2. Hover over elements to highlight them
  3. Click an element to select it
  4. Use the slider to adjust selection
  5. Click "Capture" to take screenshot

Keyboard shortcuts:

  • ESC - Cancel selection
  • ↑ / ← - Select parent
  • ↓ / → - Select child
